# Bobo Web Practice Materials

Emma and Bobo practice remotely, so formal learning materials in this repository should be published as GitHub Pages web pages.

Rules:

- Put child-facing practice HTML under `source_materials/desktop-bobo/`.
- Keep a stable latest URL when useful, for example `bobo-science-graduation-latest.html`.
- Do not publish local-only paths as the final handoff.
- Do not embed Telegram bot tokens, OpenAI keys, GitHub tokens, or other secrets in public HTML/JS.
- Keep generated question banks pre-generated and answer-checked; public pages should display, check, record progress, and route retry items only.
